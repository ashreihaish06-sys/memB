# 말씀암송 50 (Bible Memory 50) 📖✨

스마트폰의 자체 음성 인식(Web Speech API) 기능을 활용하여 **개역개정 50개 핵심 성경구절**을 실시간으로 암송하고 마음에 새기는 **설치형 웹앱(PWA)**입니다.

별도의 유료 STT/AI API 서버 없이 브라우저 자체 음성인식 기술로 동작하며, GitHub와 Vercel을 통해 간편하게 배포할 수 있습니다.

---

## 🌟 핵심 기능 및 기술적 문제 해결

### 1. 긴 문장 끊김 방지 (마디 단위 청킹 분할)
- 긴 성경 구절을 한 호흡에 낭독할 때 모바일 브라우저의 음성 인식이 중간에 끊어지는 문제를 해결하기 위해, 각 구절을 **2~6개의 자연스러운 마디(구/절)**로 분할하였습니다.
- 한 마디를 암송하면 차임벨·진동과 함께 완료 표시가 되며, 다음 마디로 이어집니다. 여러 마디를 한 번에 이어서 말해도 순서대로 연속 통과됩니다.

### 2. 한글 음성인식 오차 극복 (퍼지 매칭)
[`src/utils/hangulMatcher.ts`](src/utils/hangulMatcher.ts)
- 유니코드 **한글 자모 분해**(초·중·종성) + 발음이 구분되지 않는 모음(애/에, 왜/외/웨) 통일.
- **근사 부분문자열 검색(Sellers 알고리즘)**: 앞에 군말·이전 마디의 잔여 발화가 있어도, 인식이 중복 누적(안드로이드 Chrome)되어도 목표 마디를 찾아냅니다.
- **소비 위치 추적**: 한 번 통과한 발화는 다음 마디 판정에서 제외되어, 같은 말이 다음 마디를 잘못 통과시키지 않습니다.
- **이중 기준**: 인식이 확정(final)된 경우 70% 이상(한두 단어 오인식 허용), 아직 말하는 중(interim)인 경우 88% 이상일 때만 즉시 통과 → 말을 마치기 전에 넘어가는 조기 통과를 방지합니다.

### 3. 막힘 없는 UX 지원
- **💡 초성 힌트:** 마디의 초성(예: `ㄱㄹㅈ ㄴㄱㄷㅈ...`)을 열어볼 수 있습니다.
- **🔊 구절 듣기(TTS):** 올바른 낭독을 먼저 청취 (듣는 동안 마이크는 자동으로 꺼져 낭독 소리가 인식되지 않음).
- **⏩ 건너뛰기:** 인식이 계속 막힐 때 마디를 넘길 수 있으나, **건너뛴 마디가 있으면 암송 완료로 기록되지 않습니다.**

### 4. PWA
- `vite-plugin-pwa`(Workbox)로 앱 화면·아이콘을 오프라인 캐시, PNG/maskable/apple-touch 아이콘 포함.
- 안드로이드(Chrome)의 **[앱 설치]**, 아이폰(Safari)의 **[홈 화면에 추가]** 지원.
- 스마트폰 뒤로가기로 앱이 종료되지 않고 목록으로 돌아옵니다.

### 5. 암송 기록
- 완료 기록, 즐겨찾기, 연속 암송일수(🔥)는 기기 `localStorage`에 저장됩니다. (손상된 저장값은 자동으로 걸러냄)

> ⚠️ **알아둘 점**
> - 스마트폰의 음성인식은 보통 **인터넷 연결이 필요**합니다(오프라인에서는 화면만 열림).
> - iOS는 **홈 화면에 추가한 앱**에서 음성인식이 제한될 수 있어, 동작하지 않으면 Safari로 직접 접속해야 할 수 있습니다.
> - 브라우저 음성인식·마이크는 **HTTPS**에서만 동작합니다 (Vercel 기본 제공).

## 📚 수록된 50개 구절

본문은 대한성서공회 **개역개정** 원문과 대조 검증하였습니다. 주제별 구성:

- **A. 새로운 삶 (1~10)** · **B. 그리스도인의 양식 (11~20)** · **C. 하나님을 신뢰함 (21~30)**
- **D. 제자의 삶 (31~40)** · **E. 그리스도를 닮아감 (41~50)**

구절을 바꾸려면 [`src/data/verses.ts`](src/data/verses.ts) 의 `text`와 `chunks`를 수정하세요. (`chunks`를 이어 붙인 글이 `text`와 같아야 합니다.)

```bash
npm install

npm run build          # 타입체크 + 프로덕션 빌드
npm run lint           # 린트
npm run generate-pwa-assets   # public/favicon.svg 로부터 PNG 아이콘 재생성
```
