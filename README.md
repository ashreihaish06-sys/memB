# 말씀암송 50 (Bible Memory 50) 📖✨

스마트폰의 자체 음성 인식(Web Speech API) 기능을 활용하여 **개역개정 50개 핵심 성경구절**을 실시간으로 암송하고 마음에 새기는 **설치형 웹앱(PWA)**입니다.

별도의 유료 STT/AI API 서버 없이 브라우저 자체 음성인식 기술로 100% 무료 동작하며, GitHub와 Vercel을 통해 간편하게 배포할 수 있습니다.

---

## 🌟 핵심 기능 및 기술적 문제 해결

### 1. 긴 문장 끊김 방지 (마디 단위 청킹 분할)
- 긴 성경 구절을 한 호흡에 낭독할 때 모바일 브라우저의 음성 인식이 중간에 끊어지는 문제를 해결하기 위해, 각 구절을 **2~4개의 자연스러운 마디(구/절)**로 분할하였습니다.
- 한 마디를 암송하면 차임벨과 함께 완료 표시가 되며, 다음 마디로 부드럽게 이어집니다.

### 2. 한글 음성인식 오차 극복 (퍼지 매칭 알고리즘)
- 성경 특유의 고어, 띄어쓰기 오차, 발음 뭉개짐에 대비하여 **유니코드 한글 자모 분해(초성·중성·종성)** 및 **레벤슈타인 편집 거리(Levenshtein Distance)** 기반의 유사도 판정 알고리즘을 구현했습니다.
- 목표 마디와 75% 이상의 발음 유사도 또는 띄어쓰기 무관 부분 일치 시 자동으로 정답으로 판정합니다.

### 3. 막힘 없는 UX 지원 (힌트 & 스킵 & TTS)
- **💡 초성 힌트:** 구절이 기억나지 않을 때 마디의 초성(예: `ㄱㄹㅈ ㄴㄱㄷㅈ...`)을 열어볼 수 있습니다.
- **🔊 구절 듣기:** Web Speech Synthesis(TTS)로 올바른 낭독 음성을 먼저 청취할 수 있습니다.
- **⏩ 마디 통과(스킵):** 시끄러운 환경이나 특수 단어 인식 실패 시 스트레스 없이 다음 마디로 넘어갈 수 있습니다.

### 4. PWA (Progressive Web App) 오프라인 지원
- `vite-plugin-pwa`와 서비스 워커(`Workbox`)를 탑재하여 오프라인 캐싱 지원.
- 아이폰(Safari)의 **[홈 화면에 추가]** 또는 안드로이드(Chrome)의 **[앱 설치]**를 통해 네이티브 앱처럼 전체화면으로 사용 가능합니다.

### 5. 암송 기록 및 스트릭 관리
- 모든 암송 완료 기록, 북마크, 연속 암송일수(Streak 🔥)는 기기 내부 `localStorage`에 자동 보관됩니다.

- **A. 새로운 삶 (1~10번):** 요한복음 1:12, 고린도후서 5:17, 갈라디아서 2:20, 요한일서 5:11-12 등
- **B. 그리스도인의 양식 (11~20번):** 디모데후서 3:16-17, 여호수아 1:8, 시편 119:105, 빌립보서 4:6-7 등
- **C. 하나님을 신뢰함 (21~30번):** 베드로전서 5:7, 이사야 41:10, 빌립보서 4:13, 로마서 8:28, 시편 23:1 등
- **D. 제자의 삶 (31~40번):** 마태복음 6:33, 누가복음 9:23, 로마서 12:1-2, 고린도전서 6:19-20 등
- **E. 그리스도를 닮아감 (41~50번):** 요한복음 13:34-35, 고린도전서 13:4-5, 빌립보서 2:3-5, 갈라디아서 5:22-23 등

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드 및 검증
npm run build

## 🌐 깃허브(GitHub) 및 버셀(Vercel) 배포 가이드

### 1단계: GitHub 저장소에 올리기
1. [GitHub](https://github.com)에서 새로운 Repository(예: `bible-memorization-50`)를 생성합니다.
2. 터미널에서 다음 명령어를 순서대로 실행합니다:

```bash
git add .
git commit -m "feat: 50개 성경구절 음성 암송 PWA 앱 완성"
git remote add origin https://github.com/<본인-깃허브-아이디>/<저장소-이름>.git
git push -u origin main
```

### 2단계: Vercel 배포하기
1. [Vercel](https://vercel.com)에 로그인 후 **[Add New...]** -> **[Project]**를 클릭합니다.
2. 방금 올린 GitHub 저장소를 찾아 **[Import]**를 클릭합니다.
3. 빌드 설정(기본값 그대로 유지):
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. **[Deploy]** 버튼을 누르면 약 30초 내에 전 세계 어디서나 접속할 수 있는 HTTPS 주소가 발급됩니다!
> **중요:** 브라우저 음성인식(Web Speech API)과 PWA는 보안 정책상 반드시 **HTTPS** 환경에서만 동작합니다. Vercel에서 기본 무료 제공하는 HTTPS 주소로 스마트폰에서 바로 접속하시면 마이크 권한이 활성화됩니다.
